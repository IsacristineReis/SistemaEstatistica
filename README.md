# Sistema de Estatística de Trânsito

## 📝 Descrição
Sistema de transito operado através de uma interface de linha de comando

## 📁 Estrutura do Projeto

```
PRJ_Sistema_Transito
└── src
    ├── module-info.java
    └── sistemaTransito
        ├── ClasseMetodos.java
        ├── Estatistica.java
        └── Main.java
```

## 💡 Principais recursos

* 📊 Base de Processamento Estatístico — Fornece funcionalidades essenciais para o registro e a avaliação de métricas estatísticas no âmbito da estrutura SistemaEstatistica.
* 🚦 Módulo Dedicado de Trânsito — Incorpora o diretório PRJ_Sistema_Transito, projetado especificamente para dados do domínio de trânsito.
* 💻 Interação via Linha de Comando — Configurado para operação via terminal, permitindo a execução eficiente de operações com dados.
